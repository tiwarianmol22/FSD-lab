## Repository Overview

### What It Contains:

**Main Project**: A **Student Registration Form** with client-side validation

The repository includes:
- **form.html** - A styled HTML form for student registration with fields for:
  - Name
  - Email
  - Password
  - Mobile Number

- **script.js** - JavaScript validation logic that validates:
  1. **Name** - Must not be empty
  2. **Email** - Must not be empty (basic validation)
  3. **Password** - Minimum 6 characters required
  4. **Mobile Number** - Must be exactly 10 digits and numeric only

### What It Does:

This is a **learning project** that demonstrates:
- HTML form structure and styling
- JavaScript DOM manipulation (`document.getElementById`)
- Form validation techniques before submission
- User feedback through alert messages
- Basic input validation patterns

It's the type of beginner-to-intermediate full-stack development exercise commonly used in learning labs to teach form handling, client-side validation, and JavaScript fundamentals.
